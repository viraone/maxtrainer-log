Connect GitHub to edit

Edits are saved straight into the log file in your GitHub repo, so the page needs permission once. You only do this one time per browser.

  1. Create a fine-grained token on GitHub.
  2. Repository access: Only select repositories → viraone/maxtrainer-log.
  3. Permissions: Contents → Read and write. Generate it.
  4. Paste it below. It is stored only in this browser.
