Connect your AI trainer

The form review is done by DeepSeek. Paste your DeepSeek API key once. It is stored only in this browser and sent only to DeepSeek.

When you press Analyze, a handful of still frames from that one clip are sent to DeepSeek so it can see your form. Nothing else leaves this page.

  1. Create or copy a key at platform.deepseek.com/api_keys.
  2. Paste it below.

Connect GitHub

  1. Create a fine-grained token on GitHub, or edit the one you already have.
  2. Repository access: Only select repositories, and pick both viraone/maxtrainer-log and viraone/maxtrainer-media (the private repo that holds set videos).
  3. Permissions: Contents → Read and write. Generate it.
  4. Paste it below. It is stored only in this browser.
